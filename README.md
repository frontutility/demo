# ConnectNKT

ConnectNKT is a hyperlocal social networking frontend for Neem Ka Thana.

## Run

```bash
npm install
npm run dev
```

## Features

- Responsive public site and admin panel in one React Vite project
- Light and dark theme with local persistence
- Home feed with seeded ordering, instant filtering, and load-more pagination
- Auth, profile, village, notifications, search, post, settings, and CMS screens
- Admin dashboard, users, posts, villages, reports, blue ticks, settings, and CMS management
